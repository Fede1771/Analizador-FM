# Capturas finales de la interfaz

Las ocho imágenes de esta carpeta documentan Centro del club, Mi táctica, Propuestas, Guía para FM, ventanas angostas, Ojeo y sobrepoblación de Plantilla.

Se generaron con datos de prueba. Sirven para revisar presentación y navegación; no acreditan la alineación real del usuario ni las reglas del motor de FM.

El generador es `tools/take_final_screenshots.mjs`. La aplicación no necesita estas imágenes para ejecutarse.
