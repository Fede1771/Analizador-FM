# Roles de Football Manager: guía de las 33 capturas

Revisión: 24 de octubre de 2026. Se revisaron las 33 imágenes PNG de esta carpeta. Las descripciones siguientes son resúmenes en español de las fuentes enlazadas, no transcripciones oficiales del juego. Los nombres españoles se toman de las capturas; las equivalencias inglesas permiten buscar cada función. Los roles repetidos a izquierda y derecha se agrupan.

Con posesión (CP) describe el comportamiento cuando tu equipo tiene la pelota; sin posesión (SP), cuando la tiene el rival. Un mismo nombre puede tener una función distinta en cada fase. Fuente del sistema: [Football Manager, explicación oficial en español](https://www.footballmanager.com/es/fm26/funcionalidades/con-posesion-y-sin-posesion-la-nueva-evolucion-tactica-de-fm26).

## Alcance y nombres incompletos

Se incluyeron todas las opciones visibles, no solamente las seleccionadas en violeta. Las estrellas pertenecen a la evaluación del jugador de las capturas y no forman parte de la descripción del rol.

Las equivalencias inglesas de los nombres truncados son correspondencias inferidas mediante posición, fase y conjunto de opciones. Se conserva el texto visible con puntos suspensivos para evitar presentar como confirmado un nombre español que no se puede leer completo. Esto afecta a las variantes de mediocampista abierto SP, mediocampista de cobertura SP, mediapunta estacionario SP y delantero centro estacionario SP.

La captura 135930 permite confirmar expresamente «Mediocampista defensivo de cobertura abierta» mediante el aviso emergente. Los laterales y carrileros de ambos costados muestran las mismas opciones en las capturas, por lo que se explican juntos.
